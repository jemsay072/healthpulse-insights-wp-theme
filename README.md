# HealthPulse Insights — Custom WordPress Theme

A modern editorial WordPress theme built for healthcare publications, wellness blogs, and medical resource hubs. Focused on fast content discovery through zero-reload live search and dynamic category filtering.

> **Live Demo:** [https://healthpulse-demo.freedev.app](https://healthpulse-demo.freedev.app/)
> *(Note: All articles, author profiles, and editorial entries on the live demo use placeholder content for demonstration purposes.)*

---

## Key Features
* **Zero-Reload AJAX Live Search:** Real-time article search results powered by WordPress AJAX without refreshing the page.
* **Instant Category Filtering:** Smooth topic filtering for readers exploring health guides and medical insights.
* **Editorial Layout System:** Clean typography, featured post sections, and structured reading views styled with Tailwind CSS.
* **Newsletter Subscription UI:** Integrated signup flow built for reader engagement.

## Tech Stack
* **CMS:** WordPress
* **Backend:** PHP (`admin-ajax.php`)
* **Custom Fields:** Advanced Custom Fields (ACF)
* **Frontend & Styling:** HTML5, Tailwind CSS, JavaScript (ES6 / AJAX)

## Local Installation (XAMPP / Local WP)
1. Clone this repository directly into your WordPress `wp-content/themes/` directory:
   ```bash
   git clone https://github.com healthpulse-insights
   ```
2. Log in to your **WordPress Admin Dashboard** (`wp-admin`).
3. Go to **Appearance > Themes** and activate **HealthPulse Insights**.
4. *(Recommended)* Install and activate the **Advanced Custom Fields (ACF)** plugin so custom editorial fields render properly.
